# Colocar o ícone LucroKM na tela do celular

## Android (Chrome ou Edge)
1. Publique os arquivos na Vercel e abra o endereço HTTPS no celular.
2. Toque no botão laranja **Instalar** do próprio LucroKM.
3. Se o navegador mostrar uma confirmação, toque em **Instalar**.
4. Se o aviso não aparecer, abra o menu do navegador `⋮` e procure **Instalar aplicativo** ou **Adicionar à tela inicial**.
5. O ícone do LucroKM aparecerá na tela inicial, e o app abrirá sem a barra do navegador quando instalado como PWA.

## iPhone (Safari)
1. Abra o link HTTPS no **Safari**.
2. Toque no ícone **Compartilhar** (quadrado com seta para cima).
3. Escolha **Adicionar à Tela de Início**, depois toque em **Adicionar**.
4. O ícone aparecerá na tela inicial. Em iPhone, o botão do site exibe essas instruções porque o Safari não oferece o mesmo prompt de instalação do Android.

## Antes de testar offline
- Abra o site uma vez **com internet** para o navegador guardar os arquivos essenciais.
- Abra o ícone instalado e depois teste sem internet.
- O app salva os dados no próprio aparelho; faça backup pelo menu Configurações.
