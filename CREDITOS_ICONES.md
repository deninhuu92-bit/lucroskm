# Biblioteca de ícones — Font Awesome Free

Ícones vetoriais **Font Awesome Free** (Fonticons, Inc.) a partir de arquivos SVG do conjunto oficial, com gradientes de cores definidos para a identidade LucroKM.

- Site: https://fontawesome.com/
- Licença dos SVGs: Creative Commons Attribution 4.0 (CC BY 4.0).
- Licença completa: veja `FONT-AWESOME-LICENSE.txt`.
- Mudanças: cores e gradações personalizadas por categoria, inserção em elementos UI próprios.
- Distribuição: SVGs em `assets/icons/`, incluídos no cache do aplicativo para funcionamento offline.
