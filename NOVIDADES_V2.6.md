# LucroKM v2.6 — identidade visual oficial

- A sua logomarca LKM / LUCROS KM foi aplicada como ícone do aplicativo PWA (Android e iPhone).
- Versões específicas para 180, 192 e 512 pixels, preservando a proporção e sem distorcer a logo.
- Versão maskable com margem de segurança para lançadores de celulares.
- Favicon do navegador atualizado.
- Cabeçalho e tela de instalação mostram o ícone novo.
- Cache offline incrementado para v2.6.0.
- Arquivo original salvo em `icons/logo-original.png`.
- Todos os recursos das versões anteriores permanecem.

## Como atualizar no Vercel por GitHub

1. Abra a pasta `LucroKM_v2.6` extraída deste ZIP.
2. Selecione **os arquivos e pastas dentro dela** (não a pasta externa).
3. No repositório `deninhu92-bit/lucroskm`, clique em **Add file > Upload files**.
4. Envie os arquivos substituindo os antigos, inclusive a pasta `icons`.
5. Confirme **Commit changes** na branch `main`.
6. No Vercel, abra **Deployments** e verifique **Ready**.

Antes de publicar, faça um backup dentro do LucroKM. O aplicativo mantém o mesmo localStorage e não deve apagar registros ao atualizar, desde que use o mesmo domínio/perfil e não limpe dados do site.
